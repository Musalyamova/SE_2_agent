# Skill: Проверка на SQL-инъекции
- Ищи конкатенацию строк, которая передается в SQL-запрос (например, `"SELECT * FROM users WHERE name = '" + username + "'"`)
- Ищи использование f-строк для формирования SQL-запросов
- Если видишь `cursor.execute(...)` с переменными внутри строки, значит, это критическая уязвимость
- Рекомендуй использовать параметризованные запросы (placeholders `?`).
